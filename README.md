## Netflix EDA Dashboard

# Project Overview
This project explores Netflix titles using Exploratory Data Analysis (EDA) and Power BI to understand content distribution, movie and TV show trends, and the platform's content library.

# Objectives
- Analyze the distribution of Movies and TV Shows.
- Identify the top 10 countries by number of Netflix titles.
- Explore content trends by release year.
- Analyze content ratings and movie durations.
- Build an interactive Power BI dashboard.

# Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook / VS Code

# Key Insights
The dashboard highlights content distribution by type, country, release year, rating, and movie duration.
